# 👟 KN Store - E-commerce Platform

Un sistema integral de comercio electrónico desarrollado para modernizar y optimizar las operaciones de la tienda de calzado KN Store. Esta plataforma centraliza la gestión de ventas, el control de inventario y la atención al cliente, eliminando la dependencia de canales informales y procesos manuales.

---

## 🚀 Características Principales

- **Catálogo Digital Interactivo:** Los clientes pueden explorar fácilmente el inventario de calzado, filtrando por color, talla, marca y referencia.
- **Gestión Integral de Inventario:** Control en tiempo real de las existencias para evitar inconsistencias y pérdidas de información.
- **Sistema de Roles y Seguridad:** Control de acceso estructurado para Administradores, Managers y Clientes, garantizando la protección de los datos.
- **Logística de Envíos:** Opciones de distribución flexibles que permiten a los clientes elegir entre pago contra entrega o paquetería convencional.
- **Módulo de Servicios:** Administración y visualización clara de los servicios adicionales que ofrece la tienda.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto está construido bajo el stack MERN para garantizar un rendimiento óptimo y escalabilidad:

- **Frontend:** Next.js (App Router) con React 19
- **Backend:** Node.js, Express.js
- **Base de Datos:** MongoDB
- **Autenticación:** JSON Web Tokens (JWT)

La interfaz del ecommerce ya fue migrada a Next.js para aprovechar renderizado en servidor, rutas por archivo, mejor SEO y una base más sólida para crecimiento futuro.

## ⚙️ Instalación y Uso

Instrucciones para levantar el entorno de desarrollo local.

1. Clona este repositorio:
   `git clone https://github.com/tu-usuario/kn-store.git`

2. Instala las dependencias del backend:
   `cd backend`
   `npm install`

3. Instala las dependencias del frontend:
   `cd ../frontend`
   `npm install`

4. Configura las variables de entorno creando un archivo `.env` en el backend con tus credenciales de MongoDB y tu secreto JWT.

5. Inicia los servidores de desarrollo:
   Backend: `npm run dev`
   Frontend: `npm run dev`

## 📖 Contexto del Proyecto

Este software fue diseñado como solución a los retos operativos de KN Store. El proyecto busca impulsar la transformación digital del negocio, reemplazando el manejo manual de pedidos por WhatsApp con una plataforma robusta que permite tomar decisiones basadas en datos reales.
